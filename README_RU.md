# Mochi 1.3 — Emotion Shapes

Обновление системы выражений лица для ESP32-WROOM-32.

## Визуальная шкала эмоций
От менее приятной к более радостной:
1. **Злость** — узкие глаза; верхние внутренние уголки мягко подрезаны округлой вогнутой формой, создавая впечатление нахмуренного взгляда; маленькая перевёрнутая улыбка (хмурый рот).
2. **Грусть** — верхние внешние уголки глаз мягко подрезаны; зрачки опущены; маленькая перевёрнутая улыбка.
3. **Удивление** — широко раскрытые глаза.
4. **Нейтральное** — большие округлые глаза.
5. **Улыбка** — глаза чуть выше/шире и маленькая улыбка.
6. **Восторг** — более раскрытые глаза, улыбка и звёздочки (звёздочки пока следующий визуальный этап; DELIGHTED сейчас использует усиленную форму радости).

Срезы углов выполнены круглыми масками, без острых треугольников. Зрачки остаются подвижными и следуют за автономным взглядом и MPU6050; в грусти добавлено опущенное положение.

## Оборудование
- ESP32-WROOM-32 DevKit (`board = esp32dev`)
- OLED SSD1306 128×64, I²C адрес `0x3C`
- SDA GPIO21, SCL GPIO18
- MPU6050 на той же I²C шине, адрес `0x68` (необязателен)

## Сборка
Откройте папку проекта в PlatformIO и выполните Build. Компиляция и проверка на физической плате в этой среде не выполнялись.

## Источник визуального вдохновения
Plexynex: https://plexynex.vercel.app/ — ориентир по выразительности OLED-лица и анимациям Dasai Mochi. Реализация адаптирована для данного дисплея.
