# Mochi для ESP32-WROOM-32 DevKit

Это автономная стартовая адаптация проекта Mochi для классического ESP32-WROOM-32 (не ESP32-C3). Оригинальные `eyes.cpp` и `eyes.h` из предоставленного архива сохранены. Сетевой клиент/сервер, Wi-Fi, touch и звук пока отключены: сначала проверяем глаза на реальном OLED.

## Распиновка
- OLED SDA -> GPIO 21
- OLED SCL -> GPIO 18
- OLED GND -> GND
- OLED VCC -> питание, допустимое именно для вашего OLED-модуля (не угадывать по размеру дисплея)

Код ожидает SSD1306 с I2C-адресом 0x3C. Если модуль имеет адрес 0x3D, поменяйте `OLED_ADDRESS` в `src/main.cpp`. OLED 1.3 дюйма часто бывает на SH1106; эта сборка использует SSD1306-драйвер. Если дисплей SH1106, потребуется заменить драйвер дисплея, а не только адрес.

## Сборка/прошивка
Проект подготовлен для PlatformIO:
- Environment: `esp32dev`
- Board: `Espressif ESP32 Dev Module`
- Framework: Arduino

В VS Code с PlatformIO: открыть папку проекта, дождаться установки платформы и библиотек, выполнить Build, затем Upload. Для физической платы нужен USB-кабель с передачей данных.

## Команды Serial Monitor (115200)
- `0` нейтральное
- `1` радостное
- `2` сердитое
- `3` удивлённое
- `4` сонное
- `b` моргнуть
- `l` взгляд влево, `r` вправо, `c` по центру

## Важные ограничения
- Это исходный проект, а не готовый бинарный `.bin`: бинарник должен быть собран компилятором ESP32 под конкретную конфигурацию.
- Не подключайте OLED к питанию, пока не проверите допустимое напряжение на его плате/в документации.
- GPIO 18 выбран как SCL по просьбе пользователя; SDA — GPIO 21.
