# Mochi 1.1 — ESP32-WROOM-32

Новая версия системы лица: большие глаза, плавные переходы между эмоциями, маленькая улыбка только для радостных состояний. Отдельных бровей нет: наклон/подрезка верхней и нижней части силуэта глаз передают настроение.

Визуальный ориентир: https://plexynex.vercel.app/ — Dasai Mochi (B&W), Dasai Mochi 2/3 и Other Animation. Это вдохновение для характера и пластики лица; графика адаптирована для собственного OLED-проекта.

## Подключение
- OLED SSD1306 128x64, адрес 0x3C: SDA GPIO21, SCL GPIO18, питание 3.3V, GND.
- MPU6050 (опционально): SDA GPIO21, SCL GPIO18, питание 3.3V, GND, адрес обычно 0x68.
- OLED и MPU6050 используют общую I2C-шину.

## Сборка
Откройте папку в PlatformIO и выполните Build/Upload. Скорость Serial Monitor: 115200.

Команды Serial:
- `0` нейтральное
- `1` радость
- `2` злость
- `3` удивление
- `4` сонливость
- `5` грусть
- `6` восторг
- `7` любопытство
- `b` моргание
- `l` взгляд влево, `r` вправо, `c` по центру

## Важно
- Это исходный проект PlatformIO, не готовый объединённый бинарник для прошивки по адресу 0x0.
- Сборка и работа на физической плате в этой среде не проверялись.
- Прошивка рассчитана на SSD1306 128x64. Для неизвестной модели/драйвера дисплея настройки могут потребовать изменения.
- MPU6050 обнаруживается при запуске; если его нет, лицо продолжает работать в OLED-only режиме.
- Эффект глича длится около секунды, затем идёт пробуждение.
- Архитектура подготовлена к будущей смене платы: контакты вынесены в начало файла, логика лица не зависит от модели платы.
