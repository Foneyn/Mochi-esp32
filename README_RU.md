# Mochi ESP32 + MPU-6050

Проект для классической ESP32-WROOM-32 DevKit, OLED SSD1306 128x64 I2C и MPU-6050/GY-521.

## Подключение OLED

| OLED | ESP32 |
|---|---|
| VCC/VDD | 3V3 (если модуль рассчитан на 3.3 В) |
| GND | GND |
| SDA | GPIO 21 |
| SCL/SCK | GPIO 18 |

## Подключение MPU-6050 (GY-521)

Оба устройства используют одну I2C-шину, поэтому SDA/SCL подключаются параллельно:

| MPU-6050 | ESP32 |
|---|---|
| VCC | 3V3 |
| GND | GND |
| SDA | GPIO 21 |
| SCL | GPIO 18 |
| AD0 | GND или оставить как на модуле (обычно адрес 0x68) |
| INT, XDA, XCL | Не подключать для этого теста |

Не подключайте VCC к 5V. На некоторых платках GY-521 есть стабилизатор, но питание 3.3V — безопасный общий вариант для ESP32.

## Реакции

- Наклон корпуса — глаза плавно смотрят в сторону наклона.
- Встряхивание — кратковременное удивлённое выражение.
- Без MPU-6050 прошивка продолжит работать как обычная версия, но реакции на движение будут отключены.

Serial Monitor: 115200 baud.

- `0` нейтральная эмоция
- `1` радость
- `2` злость
- `3` удивление
- `4` сонливость
- `b` моргнуть
- `l` / `r` взгляд влево / вправо
- `c` взгляд в центр
- `?` помощь

## Сборка

GitHub Actions workflow `.github/workflows/build.yml` собирает PlatformIO проект и создаёт объединённый образ `mochi-esp32-merged.bin` для записи через ESP Web Tools по адресу `0x0`.

Это версия для SSD1306 — используйте её с тем маленьким OLED, на котором предыдущая прошивка уже показывала изображение.
