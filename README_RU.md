# Mochi 1.0 — ESP32-WROOM-32

Первая модульная основа прошивки Мочи. Визуальный ориентир — Plexynex:
https://plexynex.vercel.app/
Используются собственные упрощённые рисунки и анимации, адаптированные под OLED.

## Подключение

Текущая конфигурация:
- OLED SSD1306 I2C, адрес `0x3C`
- OLED SDA -> GPIO21
- OLED SCL -> GPIO18
- MPU6050 GY-521 SDA -> GPIO21
- MPU6050 GY-521 SCL -> GPIO18
- MPU6050 VCC -> 3V3
- MPU6050 GND -> GND

OLED и MPU6050 используют одну I2C-шину. У MPU6050 ожидается адрес `0x68`.
Если OLED не SSD1306, этот проект может потребовать замены драйвера.
Размер дисплея предполагается 128x64.

## Что реализовано

- Стартовый визуальный глич около 1 секунды (без физического замыкания SDA/SCL).
- Анимация пробуждения.
- Базовые эмоции: нейтральная, радость, восторг, удивление, злость,
  грусть, сонливость, любопытство, испуг.
- Автономное моргание и простые случайные действия.
- Реакция MPU6050 на резкое движение и наклон.
- Серийные команды для тестирования эмоций.

## Сборка

1. Установить Visual Studio Code и PlatformIO.
2. Открыть папку проекта `Mochi_ESP32_Mochi10`.
3. Дождаться установки библиотек.
4. Подключить ESP32-WROOM-32 по USB.
5. Нажать PlatformIO: Upload.

## Команды Serial Monitor

Скорость: 115200 бод.

- `0` — нейтральное лицо
- `1` — радость
- `2` — злость
- `3` — удивление
- `4` — сонливость
- `5` — грусть
- `6` — восторг со звёздами
- `7` — любопытство
- `b` — моргание
- `l` / `r` — взгляд влево / вправо
- `c` — взгляд по центру

## Важно

Это стартовая версия, а не проверенная на реальном устройстве финальная прошивка.
Компиляция и работа на конкретном дисплее здесь не подтверждены.
Перед загрузкой проверьте, что текущий маленький OLED действительно совместим
с SSD1306 и имеет разрешение 128x64.

Микрофон, сенсор касания и buzzer пока не подключены.
Код подготовлен с расчётом на дальнейшее расширение и миграцию на ESP32 Mini.
